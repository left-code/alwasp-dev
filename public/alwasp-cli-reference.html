Overview

build

alwasp build

Compile the AL project. With alwasp.json: config-driven multi-project build using targets and profiles. With --project or --project-root: direct build of discovered projects and their local dependencies, without alwasp.json. Otherwise: single-project build from app.json using alc.

$alwasp build [<targetOrPath>] [options]
